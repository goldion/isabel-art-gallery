# Game assets

Characters, props, and places from Isabel’s notebook, redrawn for games.

This pack is a **total notebook sweep**, not limited to the games in `idea.md`. Named people, unnamed extras, leftover props, and extra places are included. Repeat poses of the same person stay on that person’s sheet (leftover doodles are merged in, not saved as extra files). Crowd extras who are just round heads share `crowd-person.png`.

Each **character** is one PNG. Different poses, outfits, and transformation forms of that same character sit on the same sheet.

Character and element sheets use a **white** background so you can cut them out. Scene art lives in `backgrounds/`.

These are **not** her original scans. Originals stay in `F:\Isabel Art\` and `_derived\02_cleaned\`.

## Using them in a game

1. Copy the PNG you need into your game project.
2. Each character file is a **sheet**: crop one pose, or use the whole picture as a reference card. Extra leftover poses of the same person are already merged onto that sheet.
3. For a transparent sprite, remove the white background (or color-key white).
4. Keep names in `manifest.json` if you load assets from a list.
5. Elements follow the same rule as characters: **one object, one file**.
6. Backgrounds follow the same rule: **one place, one file**.
